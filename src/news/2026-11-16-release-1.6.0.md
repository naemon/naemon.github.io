Today we released the version 1.6.0 of naemon-core, naemon-livestatus
and naemon-vimcrypt-vault-broker. This release contains performance improvements
and some bugfixes as listed in detail on the changelog page.

Note that the NEB API version increased, so third party NEB modules have to be recompiled.

Head on to [the download section](/download) or check out the [changelog](/documentation/usersguide/whatsnew.html) for
a detailed list of changes.
